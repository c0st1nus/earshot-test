# earshot_vad_demo

Небольшой Rust-проект для проверки работоспособности VAD-библиотеки
[earshot](https://github.com/pykeio/earshot) с грубой "подстройкой" под
голос человека, который заговорил первым.

## Что делает

1. Слушает микрофон, режет аудио на кадры по 256 сэмплов (16 мс @ 16 кГц) —
   именно такой формат требует `earshot::Detector::predict_i16`.
2. Первые ~3 секунды — калибровка: программа оценивает высоту основного
   тона и громкость голоса того, кто заговорил первым, и запоминает это
   как грубый "профиль".
3. Дальше в реальном времени печатает VAD-score для каждого кадра и,
   если голос обнаружен, помечает — похож он на калиброванный профиль
   или нет.

## Важная оговорка

**earshot — это VAD (детектор голосовой активности), а не система
распознавания диктора.** Он отвечает только на вопрос "есть ли в кадре
голос", но не "чей это голос". Поэтому "подстройка под голос
инициатора" в этом демо реализована как самодельная эвристика поверх
VAD (диапазон высоты тона + громкость), а не как настоящая
верификация диктора. Это нормально работает как грубый фильтр в тихой
комнате с одним говорящим, но:

- не отличит два похожих по тембру голоса;
- собьётся при сильном шуме или при сильном изменении интонации;
- не годится для чего-либо, где нужна настоящая безопасность/точность
  (для этого нужна отдельная модель speaker embedding, например
  зашитая в whisper.cpp диаризация или сторонний speaker-id пайплайн).

## Сборка и запуск

Требуется **Rust ≥ 1.87** (крейт `earshot` использует edition2024,
которая стабилизировалась начиная примерно с этой версии) — если у вас
установлен более старый тулчейн через `apt`, обновите его через
[rustup](https://rustup.rs/):

```bash
rustup update stable
```

На Linux для захвата звука через `cpal` нужны заголовки ALSA:

```bash
sudo apt install libasound2-dev pkg-config
```

Сборка и запуск:

```bash
cargo run --release
```

## Примечание о проверке

Этот код был написан и вручную сверен с публичным API `earshot`
(`docs.rs/earshot`) и `cpal`, но **не был скомпилирован в песочнице**,
в которой я его готовил: там доступен только `rustc`/`cargo` версии
1.75 из `apt`, а `earshot` требует edition2024 (Rust ≥ 1.87), и
обновить тулчейн через `rustup` там нет сетевого доступа. Поэтому
после `cargo run` возможны мелкие шероховатости компиляции — если
что-то не соберётся, пришлите мне текст ошибки, поправим на месте.
